## CrewAI
Um *frammework* de exemplo da biblioteca `crewai` onde foi criado um agente especializado em geração de conteúdo para profissionais de tecnologia para o LinkedIn.

### Especificações

- Agente de IA especializado para criação de conteúdo
- Foco para profissionais de tecnologia
- Modelo `ollama/deepseek-r1:7b` (localhost)
- Processo sequencial de execução
